# Vidac

[English](README.md) | 简体中文

一款原生 macOS 视频播放器，支持本机语音识别与双语字幕。

Vidac 是为 Apple Silicon Mac 打造的原生视频播放器。打开文件即可播放；后台会识别语音并生成字幕，还可以借助 Apple Intelligence 翻译成双语字幕。

## 下载

请从 [GitHub Releases](https://github.com/dslmd/Vidac/releases/latest) 下载最新的磁盘映像（DMG）。

## 使用

Vidac 需要 **Apple Silicon（M 系列）芯片及 macOS 26.0 或更高版本**。

1. 从发布页面下载 `Vidac-<version>-arm64-unnotarized.dmg`。
2. 打开磁盘映像，将 `Vidac` 拖入“应用程序”文件夹。
3. 从“应用程序”中打开 Vidac。

播放器、音频工具和 Python 字幕运行环境都已随应用附带，无需安装 Homebrew 或 Python。下载包中不包含语音识别模型：Vidac 第一次生成字幕时会从 Hugging Face 下载模型（默认为 “Base” 模型，约 140 MB；应用会显示进度和“取消”按钮），此时需要联网；之后即可离线生成字幕。使用 Apple Intelligence 翻译需要在“系统设置”中开启 Apple Intelligence。实际发布包的兼容性与验证范围，请参阅[发布说明](docs/RELEASING.md)。

### 首次打开未公证的版本

目前的版本仅做了 ad-hoc 签名，尚未经过 Apple 公证，因此文件名中带有 `-unnotarized`。首次打开时 macOS 会阻止运行。允许打开的步骤如下：

1. 先尝试打开一次 Vidac，然后关闭弹出的警告。
2. 打开“系统设置 → 隐私与安全性”。
3. 向下滚动，找到 Vidac 被阻止的提示，点击“仍要打开”。
4. 确认后 Vidac 即可打开。此操作只需进行一次。

待版本使用 Developer ID 签名并经 Apple 公证后（`scripts/release.sh`），磁盘映像将改名为 `Vidac-<version>-arm64.dmg`，届时不再需要上述步骤。

### 播放

- 选择 File → Open…（打开）、按 `⌘O`，或将本地视频或文件夹拖入窗口。同时打开多个视频或一个文件夹时，会按自然顺序组成播放队列；`⌘→` / `⌘←` 切换到下一个/上一个视频，结尾处“即将播放”倒数 5 秒（按 Esc 取消）。可在 Playback → Play Next Automatically 中开关。
- 鼠标悬停在进度条上会显示时间气泡；拖动时按关键帧定位，松开时精确定位。点击时长可切换为剩余时间。
- 欢迎页列出最近的视频及其续播位置，播放会从上次停下的位置继续。
- 支持调速、跳转到时间（`⌘J`）、窗口置顶、截图（`S`，不含字幕，保存到 `~/Pictures/Vidac`）和右键菜单；详见 Playback、Video 和 Help 菜单。
- Vidac 支持“正在播放”和媒体键，播放时保持显示器常亮，并记住窗口位置、画面大小和音量。
- “Vidac → Make Default Video Player…”（设为默认视频播放器）可将 Vidac 设为访达中视频文件的默认应用。

Vidac 注册了 60 多种扩展名，包括 MP4、MKV、MOV、AVI、WMV、FLV、WebM、TS/M2TS、RMVB、MPEG、3GP、OGV、MXF 以及 H.264/HEVC 裸流；完整列表见 `scripts/make_info_plist.py`。文件能否播放取决于 libmpv 能否解码其编码格式；不支持受 DRM 保护的视频。无法打开的文件会提示原因。

## 触控板

| 手势 | 效果 |
| --- | --- |
| 双指向右 / 向左滑动 | 连续快进 / 快退；松开时精确定位 |
| 双指向上 / 向下滑动 | 增大 / 减小音量 |
| 在普通窗口中捏合 | 以窗口中心为锚点，按视频宽高比放大 / 缩小窗口 |
| 在全屏中捏合 | 缩放视频；字幕和控制栏保持原有大小 |
| 双指轻点两下 | 实际大小 |
| `⌘0` | 重置缩放 |

捏合在手势事件到达时立即生效，没有插值或拖尾动画；视频打开后，窗口会适配视频的宽高比。手势方向锁定后，斜向滑动不会同时改变进度和音量，松手后的惯性也不会继续调节。普通窗口受当前屏幕可见区域限制；全屏缩放范围为 50–300%。

## 设置

按 `⌘,`（Vidac → Settings…）打开。窗口分为三个页面，并记住上次使用的页面。

- **通用**：自动播放下一个；自动检查更新，另有“立即检查”按钮。
- **字幕**：自动字幕开关；语音模型（Tiny、Base、Small、Medium、Large v3 Turbo、Large v3，附大致下载大小和速度/准确度说明）；语音语言（自动或指定语言）；翻译开关与目标语言；显示模式（双语、仅原文、仅译文）；大小；延迟；字幕文件的保存位置；重新生成和显示文件。对已有生成字幕的视频更改模型或语言时会先询问，因为字幕将被重新生成。
- **触控板**：开启或关闭手势，并设置灵敏度。

Subtitles 菜单和控制栏上的字幕按钮提供针对当前视频的同样的快捷控制。

## 自动字幕与隐私

- 识别默认使用 mlx-whisper，模型按需下载。视频和音频默认在这台 Mac 上处理。
- 翻译默认使用 macOS Foundation Models，需要启用 Apple Intelligence 且模型可用。若不可用，Vidac 会显示原因；若某句被拒绝翻译，则保留原文，播放不受影响。翻译目标语言默认跟随系统语言。
- Vidac 生成的字幕文件，原文命名为 `<名称>.vidac.<语言>.srt`，译文命名为 `<名称>.vidac.tr.<语言>.srt`，进度记录在 `<名称>.vidac.json`。默认保存在视频旁边；若该文件夹不可写，则使用用户缓存文件夹；也可在“设置 → 字幕”中改为保存到 `~/Library/Application Support/vidac/subtitles`。
- 你自己的字幕文件（例如 `movie.srt` 或 `movie.en.srt`）存在时会被使用，且绝不会被覆盖、移动或删除：Vidac 只会改动文件名中带 `.vidac.` 的文件。0.5 及更早版本以普通文件名生成的字幕仍会被读取。
- 设置、播放位置和日志保存在当前用户的 Library 下，不应提交到源码仓库。
- 可选的 Ollama / LM Studio 兼容接口由用户自行配置；在默认设置下，媒体不会上传到任何云端翻译服务。
- 联网情况：首次需要时从 Hugging Face 下载语音模型。Vidac 每天向 `api.github.com` 查询一次最新版本以显示更新提示，不发送任何个人数据，也不发送视频相关信息。可在“设置 → 通用”（自动检查更新）中关闭。除此之外不会发送任何内容。

识别准确率和翻译质量取决于音频、语言、模型和系统可用性；不保证每一段都能被识别或翻译。

## 从源码构建

开发环境需要 Apple Silicon Mac、macOS 26 SDK 或更高版本、Xcode Command Line Tools、Homebrew 和 Python 3.12。

```bash
bash install.sh
bash build_app.sh
```

本地开发版本输出到 `build/Vidac.app`，仍可依赖本地开发环境。如需构建可移植的发布版本，请使用：

```bash
bash build_app.sh --portable
```

该过程需要下载发布用的运行环境并编译部分音频依赖，输出写入 `dist/`。开发、依赖和测试命令见 [DEVELOPMENT.md](docs/DEVELOPMENT.md)；发布前的签名、许可证以及在另一台 Mac 上的验证，见 [RELEASING.md](docs/RELEASING.md)。请勿将 `.venv`、`build`、`dist`、模型或个人字幕上传到 GitHub。

## 项目结构

```text
macos/       AppKit 窗口、视频渲染、手势、菜单、设置和字幕界面
vidac/       字幕识别、翻译、缓存和伴随进程状态
swift/       Apple Intelligence 翻译组件
scripts/     构建和发布工具
tests/       Python 回归测试和 Swift 手势行为测试
assets/      应用图标
```

Swift/AppKit 与 libmpv 在同一进程中播放，由一个 Python 子进程负责本地字幕；不会另外打开播放器窗口。原有的命令行入口仍然可用：`bash run.sh /path/to/video.mp4`；参数见 `bash run.sh --help`。命令行窗口沿用的滚轮绑定与原生应用的连续手势不同。
